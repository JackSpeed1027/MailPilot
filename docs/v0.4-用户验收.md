# v0.4 阅读清理、回复与智能起草验收

## 升级与开启回复

1. 关闭旧的 MailPilot 运行窗口，再双击项目里的 `Start-MailPilot.cmd`。不要只刷新旧页面；Python 进程需要重启才能加载新代码。
2. 在设置页面对应邮箱勾选**允许在本机手动发送回复（SMTP）**，保存。默认不开启，升级不会自动获得发信能力。
3. 邮箱官网需启用 SMTP。QQ / 163 通常使用同一服务授权码；Gmail 使用允许 SMTP 的应用专用密码。实际权限由服务商决定；若提示认证失败，回邮箱设置检查，不要填写普通密码。
4. 设置页第5部分选择回复语气、长度、语言、署名及其他习惯。署名在本机添加，不发送给模型；其他偏好会用于智能起草，不能填写密钥。

## 阅读是否干净

发一封普通新邮件，纯文本正文包含 `您好，&nbsp;请确认会议。&amp;nbsp;`。原文、摘要显示区和主题里不应看见 `&nbsp;` 字样，应显示空格。旧的本机记录也有显示层清理，不用删数据库。之前已经发到手机的旧通知无法撤回或修改。

含 `<script>` 或编码后的 HTML 字符时，仍只作为纯文本展示，不执行，也不加载远程图片。

## 手动回复（请使用自己的测试邮箱）

1. 从你控制的另一个测试邮箱给已连接账号发新邮件，进入邮件详情，点击**写回复 / 智能起草**。
2. 核对发件邮箱是实际收件账号。收件人优先 Reply-To，缺少时为 From；本版只回复一个地址，不“回复全部”，不抄送、不附件、不自动引用正文。
3. 写好主题和正文，点击**保存草稿并预览**。此时只落本机数据库，不能已发信。
4. 预览里可点击**修改草稿**，保存后核对最新全文。可以关闭、重新打开原邮件，继续查看草稿。
5. 只有点击**确认发送这封回复**才发信。先用低风险合成正文测试，在你的收件测试邮箱确认收到，检查 From / To、主题、中文正文、线程回复是否正确。
6. 同一草稿已提交后不能再次提交。服务器接受不代表对方已读或必然进入收件箱；不会承诺原邮箱“已发送”文件夹自动同步。

旧邮件未保留 Reply-To 时页面会提示按 From 回复；请核对地址，必要时回原邮箱回复。保护邮件、多个/无效回复地址、已变更的来源账号不在本机直接回复。

## 智能起草（调用真实模型，有费用）

1. 对普通新邮件启用模型与邮箱云授权。收件时未授权的旧邮件，不因为后来勾选就补传。
2. 点击**按我的偏好智能起草**。系统最多3轮模型请求，模型只可选择“读取当前邮件”“读取回复偏好”两个只读工具，没有 SMTP 或发信工具。
3. 成功后应显示草稿而非已发送，末尾包含你设置的署名。打开**查看智能起草处理步骤**，看到实际工具名和请求耗时；这不是模型内部思维。
4. 核对重要事实、时间、价格和承诺，未知内容应待确认。工具调用约束不能保证语义永远正确。修改满意后，再由你确认发送。
5. 回复语气/语言是生成偏好，效果需真实验收；目前没有自动训练“你的历史习惯”，也没有 RAG 查历史邮件。
6. 超过12000字符、原文截断、验证码保护或无云授权时不能智能起草，可手动回复。模型不支持工具调用、输出截断、格式不符合或额度耗尽时应明确失败，不生成伪造的成功草稿。

## 看不到模型调用记录怎么办

本地邮件格式解析（MIME、HTML、实体空格）不需要模型。中文摘要、全文翻译、智能起草才调用所配置模型。

- 邮件详情会显示**结果来源：大模型生成 / 本机提示**。后者不是有效模型摘要。
- 设置页模型区显示本机今日尝试与收到接口响应次数；摘要、分段翻译、Agent 都计入。响应次数不等于有效输出次数，也不等于服务商账单。
- 确认 API 基础地址、模型名称、Key 所属账号/项目与后台日期筛选一致；程序无法直接检查你的服务商账单。
- 本机关闭模型、未授权、缺少 Key、达到限额、敏感保护均可不产生调用。旧结果直接显示，不会为每次打开页面调用模型。
- 智能起草正常通常2次请求（工具选择一次、草稿一次），部分模型分开选择工具则3次。测试后用本机次数核对后台即可，不需要暴露 Key。

## 发送失败如何处理

认证/连接发生在邮件提交前失败，显示发送失败；提交期间断线可能已被服务器接受，显示**结果不确定**，不要直接重发。程序关闭或崩溃期间的发送在下次安全启动标为不确定，保留记录。不自动重试 SMTP。

先核对你控制的收件方和原邮箱。确认未收到后，再从原邮件新写一份回复；这会是一封新邮件，用户需要自行承担重复发送判断，系统不能保证严格 exactly-once。

## 开发验证与仍需你测试

自动测试使用合成数据与模拟 SMTP/模型，没有替你发送真实邮件或调用实际 Key。请重点验证三个服务商实际 SMTP 权限、线程回复、你的模型工具调用兼容性、回复语气及完整性。当前无“已发送”文件夹 IMAP 追加、回复全部、附件回复、自动回复、用户画像自动学习、RAG、多设备同步或独立安装包。

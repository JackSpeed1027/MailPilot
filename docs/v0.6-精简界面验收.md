# v0.6：精简界面与验收

2026-10-13。收到用户“界面仍冗余、需要美观”的反馈后，本轮优先重做阅读体验；安装包、启动管理和新 Agent 工具没有混入本次交付。

## 升级后先做这一步

关闭旧 MailPilot 运行窗口，重新双击项目根目录 `Start-MailPilot.cmd`。单纯刷新浏览器不会加载新版 Python 模板。个人配置、密钥和邮件记录保留，无需重新注册模型或 WxPusher。

## 页面如何使用

- **邮件首页**：只保留搜索、邮箱筛选、邮件数量和列表。点整条邮件即可阅读；没有搜索条件时不显示“清除筛选”。待处理和附件用小标签提示；正常推送状态、token 统计不再重复出现在每封邮件上。
- **分类**：桌面从左侧选择全部/需要行动/需要检查/含附件。手机从底部导航切换主要分类，“只看含附件”在邮件数量旁。取消了重复的一排分类标签。
- **阅读**：先显示主题、发件人、实际收件邮箱和回复入口，下面是摘要、中文译文、原文。完整 To/Cc、时间、投递状态收进“查看完整来源与投递状态”。没有附件或回复记录时不展示空面板。正文和译文没有被删除或缩短。
- **设置**：邮箱显示为备注和地址列表，点“管理”展开对应账号。模型、推送、隐私和回复按用途展开，不再有步骤编号。字段解释在“填写说明”中，密钥已配置/未配置状态仍直接可见。
- **保存失败**：需要修正的设置分组会展开，普通输入和选项保留；帮助说明继续收起。新输入的授权码、API Key 不回显，需要重新填写。保存未成功时原配置不变。
- **错误信息**：收件尚未启动、连接或推送出错时仍显示提醒，连接详情自动展开。精简界面不隐藏故障。

## 请验收

1. 邮件列表能否一眼看到主题、来源和重点；点击邮件空白区域也应打开。
2. 搜索后阅读，再返回列表，关键词、邮箱和页码是否保留。
3. 英文/日文原文与全文翻译能否通过阅读导航找到；翻译失败/部分翻译提示仍应保留。
4. 设置“管理”和“填写说明”能否展开；修改选项后收起再保存，选项不应丢失。
5. 通过旧版本验收使用的测试邮箱检查回复流程。发送仍需要你预览并确认，模型没有自动发信能力。

## 智能体模块的实际进度

v0.4 已加入受限回复 Agent：用户点击起草 → 模型选择读取当前邮件和读取回复偏好工具 → 校验草稿 → 用户编辑与预览 → 人工确认发送。工具调用最多三轮，共享模型调用上限。它不是仅换了名字的摘要函数，但范围目前只限于当前一封邮件。

**下一个智能体功能版本**优先增加跨邮件只读助手，例如“这周哪些邮件需要处理”。实现顺序：

1. 限定邮箱、时间、数量的邮件搜索工具，以及读取指定邮件工具；先本机关键词检索。
2. 用户提问触发模型选择工具，程序校验参数、读取权限、调用上限与云处理授权。
3. 回答提供可点击的真实邮件来源；找不到时明确说不足，不能编造邮件、引用或待办。
4. 用同一批合成问题评估检索召回、引用准确性、费用和响应时间，再决定引入向量 RAG。

RAG 解决“找相关上下文”的问题，不能替代授权检查、工具约束和回答校验。附件解析、安装包与安卓继续是独立阶段；本版没有提前增加 Redis、MySQL 或向量数据库。

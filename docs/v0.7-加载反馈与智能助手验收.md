# v0.7：加载反馈与跨邮件智能助手验收

2026-10-13。新增的是受限的只读工具调用 Agent，可以搜索和阅读本机已接收邮件，生成带原文依据的回答；没有自动发信、删除、修改、附件解析或多轮聊天记忆。

## 升级和使用

关闭之前的 MailPilot 运行窗口，重新双击项目根目录 `Start-MailPilot.cmd`。网页刷新不能让旧进程加载新代码。邮箱、模型 Key 与推送配置保留，无需重新申请。首次新版启动会在原 SQLite 数据库中增加 `assistant_runs` 表，保存问题、范围、答案、工具步骤和状态，不删除旧表或邮件。

### 智能起草的等待体验

点击“按我的偏好智能起草”，按钮立即显示旋转图标与“正在智能起草”，同页提交按钮暂时禁用，防止重复操作。等待时显示经过的秒数，30秒后提示仍在等待；不会显示虚构的进度百分比。完成后自动进入草稿预览；模型失败会显示错误，允许重新起草或手写。

保存设置、保存草稿和确认发信也有提交提示。设置成功以正常提示显示，并保持分组收起。页面返回时恢复按钮状态；服务器仍以唯一编号和草稿修订号阻止重复调用/发信。离开页面不会撤回已经发出的模型或 SMTP 请求；界面加载状态不是取消功能。关闭 JavaScript 后原表单流程仍可用，但没有自定义动画。

跨邮件助手运行时仍能保存设置、撤销云处理授权；下一次请求前与响应返回后都会重新校验。当前已发出的请求无法撤回。只允许同时处理一个跨邮件问题，另一个提交会提示稍后再试。回复起草仍沿用原有配置锁，不能把它当作可随时取消的后台任务。

### 跨邮件智能助手

1. 打开导航中的“智能助手”。手机底部也有该入口。
2. 输入一个明确问题，例如“最近有哪些邮件需要我处理？”或“项目报价邮件里提到了哪些金额和截止时间？”
3. 选择一个已授权邮箱，或所有已授权邮箱；选择最近1/7/30/90天。时间依据本机接收时间，滚动7天不是自然周。只搜索本机已收邮件，首次连接跳过的旧邮件不会凭空出现。
4. 可以勾选“只检索已识别有待办的邮件”。这会依赖此前摘要结果；未完成分析的邮件可能没有待办标记。
5. 点击“询问智能助手”。问题和检索到的已授权普通邮件会交给你配置的模型，有调用费用，与摘要/翻译/回复共享每日上限。
6. 回答显示候选数量、实际读取数量、中文结论、可点击邮件主题和原文证据。点击来源回到邮件，核对原文和译文。最近的问题在折叠区域中查看，每个问题独立执行，不会自动把历史对话作为上下文。

必须启用模型、配置 Key，并为对应邮箱允许云处理。收件时未授权的邮件不会因后来打开开关而被补传；当前撤销授权的账号、敏感验证邮件和账号地址不匹配的旧记录也不交给助手。

## 第一版检索边界

- 关键词搜索主题、清洗正文和摘要，不保证语义近似或跨语言召回。
- 每次搜索最多10封，最多3次搜索；最多读取4封，单封正文最多6000字符，合计最多20000字符，最多5轮模型请求、7次工具调用。
- 超长正文明确标记为部分内容，引用来自已读取部分，不能当作全文结论。
- 程序校验引用编号是否已读取，以及证据是否逐字来自原文/主题。**这能拒绝虚构来源，但不能证明模型对引用的解释一定正确**，重要事项仍要核对邮件。
- 没有命中时显示本机生成的“未找到”提示，不能把它解读成所有邮箱中都没有相关事项。
- 本机仍使用 SQLite；没有 MySQL、Redis、向量服务或额外 Python 依赖。邮件地址和链接在模型上下文中按现有规则脱敏，附件不读取。

## Agent 与 RAG 怎样学习

本版的流程是：用户选范围 → 模型选择 `search_mail` → 程序检查参数和授权、查询 SQLite → 模型选择 `read_mail` → 限量清洗正文进入上下文 → 生成回答 → 校验引用 → 本机保存并显示。

这已经是有工具选择和受限执行的 Agent，同时采用检索增强的思路。RAG 不一定要使用向量数据库；本版用关键词检索，还没有 embedding 或向量检索。后续先收集合成问题与期望来源，评估召回、引用准确性、耗时和费用，再针对跨语言/同义表达不足增加向量检索。没有证据前不写“提升XX%”。

## 请验收

1. 点击智能起草后，是否立刻有旋转图标和等待文字，能否避免重复点击；完成后是否自动显示草稿。
2. 提一个明确问题，选择有普通邮件的已授权邮箱，确认回答能点击真实来源，引用确实出现在邮件中。
3. 问不存在的关键词，确认是明确的未找到/不足提示，没有虚构邮件。
4. 缩小到最近1天或指定邮箱，检查回答范围；留意它没有承诺检索全部邮件。
5. 测试“只检索有待办”与普通检索的区别；包含外文时检查模型是否能用中文解释原文依据。
6. 关闭某个邮箱的云处理授权，再针对该邮箱提问，应提示不可使用或不显示该邮箱选项，不应再次上传它的正文。
7. 在模型服务商后台检查真实调用。开发验证使用模拟模型；你的验收才会验证当前账号、模型的实际工具支持、费用和回答质量。

## 开发验证范围

135项独立离线回归（原有120项 + 新增15项），覆盖授权、敏感邮件排除、时间/邮箱筛选、SQL参数与字面通配符、工具限制、未读取邮件引用、虚构证据、模型截断、GUI慢请求期间撤销授权、单问题并发保护、调用上限、重复提交、失败恢复、CSRF/Origin与脚本nonce。

浏览器用合成邮件和8秒模拟慢请求验证加载圈、等待状态、自动进入草稿/答案、搜索与读取记录、可点击来源和390px手机布局。没有调用真实模型、推送或SMTP；Android真机、长期运行和实际召回率仍需后续测量。

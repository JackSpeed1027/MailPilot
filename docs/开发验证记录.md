## 尚需用户验证

1. QQ/163 的 IMAP 授权码是否可登录，网易 ID 命令在真实服务器上是否满足要求。
2. Gmail 是否提供应用专用密码、网络是否可达；本版尚无 OAuth。
3. 模型 API 的实际权限、返回格式、中文摘要质量、延迟和费用。
4. WxPusher 应用与 UID 是否正确，手机是否收到，以及接收端的通知展示效果。
5. 真实断网、重启和一天使用后的漏推或误判情况。

详情见 用户测试清单.md。离线模型和通道测试不证明真实账户或手机端已成功。

## 上游接口依据

- [WxPusher 官方发送 API](https://wxpusher.zjiecode.com/docs/api-reference.html)：采用 appToken、content、contentType=1、summary、唯一本人 UID；接口成功表示异步任务创建，不代表手机可见。
- [Google 官方应用专用密码帮助](https://support.google.com/accounts/answer/185833?hl=zh-Hans)：要求两步验证；部分组织、仅安全密钥和高级保护账号可能无法使用。
- DeepSeek 官方 API 文档本次网络读取超时，默认接口与模型名称保留为用户可修改的示例，实际可用性由 test-model 验证。未核实当前价格，没有“每月必定低于某金额”的承诺。
